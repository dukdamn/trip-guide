# 여행 MD 작성법 v1.1

어느 나라든 이 형식 하나로 씁니다. 빈 틀: [`templates/blank-trip.md`](../templates/blank-trip.md)
예시: [다낭 4인](../trips/danang-2026.md) · [오사카 2인 샘플](../trips/sample-osaka.md)

---

## 1분 요약

1. **맨 위 4줄만 필수**: 제목, 나라, 날짜, 인원
2. 한 줄 = 하나. 칸은 ` | ` 로 나눔
3. 장소는 **구글맵 [공유] → 링크 복사 → 붙여넣기**. 주소·좌표 몰라도 됨
4. 시간 모르면 `오후: 제목`, 그것도 모르면 그냥 `제목`
5. 예산은 `58만`, `2,900엔`, `2만원`처럼 편하게. 끝에 `1인` / `전체`

---

## 1. 맨 위 설정

```yaml
---
title: 다낭 & 호이안 트립
country: 베트남                     # 한글·영어·일본어·코드(vn) 다 됨
dates: 2026-09-24 ~ 2026-09-27
people: 4
---
```

선택 항목 (안 쓰면 자동):

| 항목 | 기본값 | 설명 |
|---|---|---|
| `rate` | 국가 팩 값 | 현지 돈 1 = 원화 얼마. 예: 베트남 `0.054`, 일본 `9.1` |
| `home_currency` | `KRW` | 일본 친구용이면 `JPY` |
| `lang` | `ko` | 화면 언어 `ko` / `ja` / `en` |
| `currency` | 나라에 맞게 자동 | 표에 없는 나라만 직접 (예: `EUR`) |
| `badge`, `cities`, `id` | — | 헤더 배지, 도시 목록, 주소용 이름 |

## 2. 칸 규칙

첫 칸은 **제목**. 나머지 칸은 순서 상관없이, 모양을 보고 알아서 구분합니다.

| 이렇게 쓰면 | 이렇게 인식 |
|---|---|
| 구글맵 링크 | 지도 버튼 (+ 링크에 좌표 있으면 지도 핀) |
| 다른 링크 (블로그·인스타·예약) | 참고 링크 버튼 |
| `→ 도보 5분` | 다음 장소까지 이동 |
| `💰 10만~30만₫` | 가격대 |
| `💡 웨이팅 있음` | 메모 |
| `⛔ 임시휴업` | 상태 |
| `📅 Day 2` | 일정에 넣은 날 |
| 그 외 글 | 설명 |

> **구글맵 링크 종류**: 앱의 공유 링크(`maps.app.goo.gl/…`), 브라우저 주소창 링크(`google.com/maps/place/…`), 검색 링크 모두 됩니다.
> 공유 링크는 짧아서 좌표가 안 들어 있어요. 지도 버튼은 정상 동작하고, 일자별 지도 핀만 빠집니다.
> **핀까지 원하면**: 공유 링크를 브라우저에서 한 번 열고 → 주소창의 긴 링크를 복사해서 붙여넣으세요. 긴 링크엔 좌표가 들어 있어요.

## 3. 섹션

섹션 이름은 한국어·영어·일본어 모두 됩니다. 필요 없는 섹션은 통째로 빼도 됩니다.

### `## 항공`
```
- 가는 편 | 2026-09-24 | 인천 → 다낭 | 22:30 도착
- 오는 편 | 2026-09-27 | 다낭 → 인천 | 23:30 출발
```

### `## 숙소`
```
- 푸라마 리조트 | 2026-09-25 ~ 2026-09-27 | 라군풀, 전용 비치 | https://maps.app.goo.gl/…
```

### `## Day 1 · 버튼이름 · 도시` — 날짜는 자동 계산 (적어도 됨)
```
## Day 1 · 시내·밤 · 다낭
- 09:00 한시장 구경 | 과일, 커피 | → 도보 4분 | https://maps.app.goo.gl/…
- 17:00 목식당 #예약 | 칠리크랩 | https://maps.app.goo.gl/…
- 오후: 리조트 수영 #자유
- 야시장은 시간 되면 #옵션
```
- 시간: `09:00` 또는 `새벽: / 아침: / 오전: / 점심: / 오후: / 저녁: / 밤:` 또는 생략
- 태그 (제목 끝): `#예약` `#옵션` `#미정` `#자유`
- 도착일 밤처럼 일정이 거의 없는 날은 `Day 0`부터 써도 됩니다.

### `## 장소` → `### 지역`
```
### 시내
- [맛집] 안토이 | 반쎄오, 분짜 | 💰 10만~30만₫ | 💡 웨이팅 있음 | https://maps.app.goo.gl/…
- [카페] 콩카페 | https://maps.app.goo.gl/…
- 한시장 | https://maps.app.goo.gl/…          ← 종류 빼면 [놀거리]
```
종류: `[놀거리]` `[맛집]` `[카페]` `[술집]`(바·펍·클럽) `[쇼핑]` `[스파]`

### `## 먹어볼 것`
```
- 반쎄오 | 바삭한 부침개
```

### `## 예산`
```
- 교통 | 그랩 (공동, 카드결제) | 300만 | 전체
- 식비 | 목식당 | 55만 | 1인
- 통신 | eSIM | 1.5만원 | 1인
```
- 금액: `580000`, `58만`, `1.5k`, `2,900엔`, `2만원`, `$25` 다 됩니다. 통화를 안 쓰면 **현지 돈**.
- 끝 칸 `1인` / `전체`: 화면에서 1인 ↔ 전체(×인원) 버튼으로 바꿔 볼 수 있어요. 비우면 섹션 제목 기준 (`## 예산 (전체)` 면 전체, 아니면 1인).

### `## 팁`, `## 준비물` → `### 그룹`
일반 목록. 팁은 국가 팩 팁 위에 표시됩니다. 준비물은 체크박스로 나옵니다 (`- [ ] 여권` 형식도 됨).

## 오류가 나면

변환기가 줄 번호로 알려줍니다. ❌는 고쳐야 하고, ⚠️는 그냥 둬도 만들어집니다.

```
⚠️  짧은 구글맵 링크 12개는 좌표가 없어 지도에 핀이 안 찍혀요 (링크 버튼은 정상)
⚠️  국가 팩(packs/jp.json)이 없어요 → 회화·현지 팁 없이 기본 화면으로 만들어져요
❌ 오류 1건
  - 41행: 예산 금액을 못 읽었어요 → "천엔쯤" (예: 58만, 580000, 2만원)
```
